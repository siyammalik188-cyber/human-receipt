# Contributing

This repo is an [Agent Skill](https://agentskills.io/specification). Keep it installable.

## Rules

- `name` in `SKILL.md` must stay `human-receipt` and match the folder name.
- Keep `SKILL.md` under 500 lines. Put detail in `references/`.
- Description must say **what** the skill does and **when** to use it.
- Do not add secrets, telemetry, or install scripts that phone home.
- Prompts and checklists should stay copy-pasteable.

## Suggested edits

| Change | Where |
|---|---|
| Operating loop | `SKILL.md` |
| Full skill catalog | `references/catalog.md` |
| Overlooked skills | `references/underrated.md` |
| Templates | `references/prompts.md` |
| Steps / boxes to tick | `references/checklists.md` |
| Install instructions | `README.md` |
